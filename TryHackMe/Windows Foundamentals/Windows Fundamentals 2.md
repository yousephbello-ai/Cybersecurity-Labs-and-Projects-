Windows Fundamentals 2: System Administration & Security
* **System Configuration (`msconfig`):** Managing boot configurations, service states, and system startup behavior.
* **Computer Management MMC Snap-ins:** Deep dive into Event Viewer, Device Manager, and Shared Folders.
* **Windows Registry (`regedit`):** Understanding key hives (`HKLM`, `HKCU`), startup run keys, and how configuration settings are stored.
* **Administrative Tools & Security:**
  * **Resource Monitor:** Analyzing real-time network, disk, memory, and CPU activity per process.
  * **Local Security Policy (`secpol.msc`):** Enforcing account lockouts, password rules, and audit strategies.
