## 🛠️ Key Commands & Concepts Learned

### 1. System & Terminal Basics
* `whoami`: Displays the username of the currently active session user.
* `echo`: Outputs text arguments straight to the terminal window (e.g., `echo "TryHackMe"`).

### 2. Filesystem Navigation
* `ls`: Lists files and folders within the current directory.
* `cd`: Changes your working directory to a specified path.
* `pwd`: Prints the full absolute path of your current working directory.
* `cat`: Concatenates and displays file contents on the screen.

### 3. Finding Files & Filtering Text
* `find`: Searches for files and directories matching target search criteria.
* `grep`: Searches inside files for specific patterns or strings (essential for log analysis and CTF flags).

### 4. Shell Operators & Redirection
* `&`: Executes a command in the background, freeing up the terminal.
* `&&`: Chains
