Web Application Basics

This repository contains my personal notes, key takeaways, and lab documentation completed during the **Web Application Basics** module on TryHackMe.

## 📌 Module Overview
The Web Application Basics module covers fundamental web technologies, client-server architecture, and basic web security principles essential for penetration testing and defensive analysis.

## 🔑 Key Concepts Learned
- **HTTP/HTTPS Protocols:** Understanding request methods (`GET`, `POST`, `PUT`, `DELETE`), headers, status codes, and HTTPS encryption mechanisms.
- **Web Architecture:** How clients, web servers, databases, and APIs interact in multi-tier applications.
- **Cookies & Sessions:** Session management, statelessness, state tracking, and authentication mechanics.
- **Intro to Web Vulnerabilities:** Basics of OWASP Top 10 concepts including Input Sanitization, SQL Injection concepts, and Cross-Site Scripting (XSS).
- **Tools & Inspection:** Utilizing browser Developer Tools (Network tab, Storage, Inspector) to analyze web traffic and DOM structures.

## 🛠️ Hands-On Skills
- Inspecting and modifying HTTP request/response headers.
- Analyzing cookies and JWT token structures.
- Identifying server configurations and technology stacks using headers and dynamic responses.
