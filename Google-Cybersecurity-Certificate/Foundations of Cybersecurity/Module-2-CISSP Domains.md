# Module 2 Notes: The 8 CISSP Security Domains & Core Concepts

## Overview
This module covers foundational security principles, focusing on the eight Certified Information Systems Security Professional (CISSP) domains and how organizations structure defense strategies against cyber attacks.

## The Eight CISSP Security Domains
* **Security and Risk Management:** Defines security goals, compliance, risk management, and business continuity.
* **Asset Security:** Securing digital and physical assets, data privacy, and resource retention.
* **Security Architecture and Engineering:** Designing systems, networks, and applications securely from the ground up.
* **Communication and Network Security:** Securing network components, protocols, and communication channels.
* **Identity and Access Management (IAM):** Controlling user access, authentication methods, and administrative rights.
* **Security Assessment and Testing:** Evaluating system security through audits, vulnerability scans, and penetration tests.
* **Security Operations:** Managing day-to-day security operations, monitoring incidents, and executing incident response plans.
* **Software Development Security:** Enforcing security standards throughout the software development lifecycle (SDLC).

## Key Takeaways
* **Attack Types & Threat Actors:** Identifying various vectors (phishing, malware, social engineering) and understanding attacker motivations.
* **Core Principle:** Defense-in-depth requires aligning technical controls across multiple CISSP domains.
