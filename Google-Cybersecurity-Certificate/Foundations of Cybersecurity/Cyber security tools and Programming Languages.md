 # Module 4: Cybersecurity tools and programming languages
**Google Cybersecurity Certificate – Foundations of Cybersecurity**

## Overview
This module introduces the main tools and programming languages used by security analysts to identify, monitor, and reduce risk.

---

## 1. Common Cybersecurity Tools

### SIEM Tools (Security Information and Event Management)
- Collect and analyze log data from across an organization
- Help detect threats by generating alerts
- Examples: **Splunk** and **Chronicle** (Google)

### Network Protocol Analyzers
- Capture and examine network traffic
- Help investigate suspicious activity
- Common tools: **Wireshark** and **tcpdump**

### Playbooks
- Step-by-step guides for responding to specific security incidents
- Help teams respond consistently and quickly

---

## 2. Programming Languages in Cybersecurity

Security analysts use programming to automate tasks and work more efficiently.

| Language | Main Use in Cybersecurity |
|----------|---------------------------|
| **Python** | Automating tasks, analyzing data, writing scripts |
| **SQL**    | Querying databases to find security-related information |
| **Linux**  | Command-line tools and system management (very common in security roles) |

> No prior programming experience is required in this certificate — later courses teach Python, Linux, and SQL from the basics.

---

## Key Terms
- **SIEM** – Tool that collects and analyzes security logs
- **Network protocol analyzer** – Tool that captures and inspects network traffic
- **Playbook** – Documented steps for handling a security incident
- **Python / SQL / Linux** – Core technical skills for entry-level cybersecurity roles
