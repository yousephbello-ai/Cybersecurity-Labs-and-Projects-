# Module 2: Play It Safe - Manage Security Risks

Documentation and key takeaways from Module 2 of the Google Cybersecurity Professional Certificate.

## 📌 Overview
This module focuses on how organizations identify, assess, and mitigate security risks using established frameworks and security controls.

## 🔑 Key Concepts & Frameworks
- **NIST CSF Core Functions:** 
  - *Govern:* Organizational governance and risk management strategy.
  - *Identify:* Asset management and risk assessment.
  - *Protect:* Access control, data security, and awareness training.
  - *Detect:* Anomalies and events monitoring.
  - *Respond:* Response planning and mitigation.
  - *Recover:* Restoration planning and improvements.
- **Risk Management Equation:** Risk = Likelihood $\times$ Impact.
- **Security Controls:** 
  - *Administrative:* Policies, procedures, and training.
  - *Technical:* Firewalls, encryption, and access controls.
  - *Physical:* Guards, biometric locks, and server room security.

## 🛠️ Practical Exercises & Labs
- Analyzed organizational scenarios to determine appropriate security controls.
- Evaluated risk mitigation strategies using compliance standards and frameworks.
- Structured incident response playbooks for common security events.
